# bank-recommendation-engine
Learning project: a next-best-action recommendation engine for bank customers, using ML on banking data.
## Study plan

### Phase 1: Data and your first model (week 1)
- [x] 1. Setup and first look at the data
- [x] 2. What drives a yes
- [x] 3. First model: one-hot encoding, train/test split, logistic regression, yes-probabilities
- [x] 4. Is the model any good? Scaling, accuracy vs precision and recall, the confusion matrix
- [x] 5. Stronger models: decision trees and random forests, compared fairly

### Phase 2: Loan risk (week 2)
- [ ] 6. A credit risk dataset, plus cleaning missing and messy data
- [ ] 7. Predicting who will struggle to repay, and explaining why (SHAP)

### Phase 3: The recommendation engine (week 3)
- [ ] 8. Generate realistic fake bank customers
- [ ] 9. Combine rules and model scores into a next best action, with tiers
- [ ] 10. Move code into Python files and save trained models

### Phase 4: Deploy it (week 4)
- [ ] 11. Build an API for customer recommendations
- [ ] 12. Build a dashboard and put it online

### Phase 5: Thinking like a bank (weeks 5–6)
- [ ] 13. Batch scoring: score all customers every night
- [ ] 14. Optional: AI-written customer messages
- [ ] 15. Monitoring, fairness, and data privacy
- [ ] 16. Final polish: README, demo, and presenting at BK
